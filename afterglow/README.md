# 余音音乐播放器

参考汽水音乐桌面布局的网页音乐播放器。默认进入方形封面播放页：歌名位于封面下，有歌词时右侧同步显示。桌面保留导航和底部播放栏，背景随封面取色；H5 使用独立单列布局。音乐库、歌单和队列共享持续播放状态。

## 双击使用

在上一级 `bofangqi` 文件夹中：

- 双击 `启动播放器.command`：准备前端文件，启动本机服务，并打开默认浏览器。重复启动会复用已有服务。
- 双击 `关闭播放器.command`：校验服务身份后关闭对应实例。

当前电脑已安装依赖。首次在新电脑启动需要 Node.js 和 npm，以及安装依赖时的网络连接。关闭启动终端不会关闭服务；关闭服务后，浏览器标签页可自行关闭。

默认地址为 `http://127.0.0.1:4173`。端口被占用时，会尝试 4174 至 4193，并在终端显示实际地址。服务仅监听本机回环地址，不向局域网开放。

## 功能

- 本地文件多选、拖放、文件夹导入；读取歌名、歌手、专辑、内嵌封面与时长。
- 添加 HTTP / HTTPS 音频直链；链接可选择仅本次使用或保存到浏览器。
- 播放、暂停、切歌、进度拖动、音量和静音。
- 顺序播放、单曲循环、随机播放，以及下一首播放、队列增删与清空。
- 播放栏右侧定时停止：15/30/45/60/90/120 分钟预设、自定义 1–180 分钟、剩余倒计时和取消；到期暂停并保留播放位置。
- 歌曲搜索、排序、专辑网格、收藏、最近播放、自建歌单和歌曲信息编辑。
- 听歌模式：统一展示真实专辑与歌单的封面卡片，点击进入对应歌曲列表。
- 从封面取色，背景、侧栏与底部播放栏同步渐变；图片受限时回退中性配色。
- 已有歌词随播放时间高亮和滚动、点击歌词跳转；手动浏览时暂停跟随，并提供回到当前句的入口。
- 播放内容上滑覆盖音乐库、下滑收起，侧栏与底栏保持固定，音乐库按页面恢复浏览位置，支持减少动态效果。
- IndexedDB 保存曲目信息、收藏、歌单、队列、当前歌曲和偏好；刷新后不自动播放。
- 已加入 Scott Buckley 的 Undertow、Hiraeth、Solace 三首完整纯音乐，使用官网音频直链并展示作者及 CC BY 4.0 署名。
- 另有三段原创合成纯音乐试听和一份明确标注的歌词同步测试文件。

本地音频文件无需上传。浏览器刷新后需重新选择原文件，元数据、收藏和歌词保留。远端播放需要源站允许访问且音频格式受浏览器支持；音乐平台分享网页不能作为音频直链。没有内置平台曲库或自动联网匹配歌词。

## 操作提示

- 音乐库中的“播放器”或底栏封面打开聆听页；聆听页左上角返回音乐库，右上角打开队列或导航和音量菜单。
- 歌曲末尾的更多菜单可选择下一首播放、编辑信息或加入歌单。
- Space 播放或暂停，Shift + 左右方向键切歌；输入框、对话框和控件获得焦点时不会触发全局快捷键。
- 远端链接修改后下次播放生效。带访问令牌的链接默认不持久保存，选择保存前请注意本机可见性及链接过期问题。

底部播放栏的倍速按钮可选 0.5× 到 3×，切歌与刷新后保留选择。播放栏按钮在鼠标悬停或键盘聚焦时显示提示；点击倍速按钮可打开选择面板，Escape 关闭。

## 开发

```sh
npm ci
npm run dev
npm run build
npm test
node scripts/service.mjs start
node scripts/service.mjs stop
```

开发使用 React、TypeScript 与 Vite，依赖版本通过 `package-lock.json` 锁定。运行 TypeScript 单元测试需要支持类型剥离的 Node.js；当前验证环境为 Node.js 24。

服务状态和日志存放在 `.runtime/`，已排除版本控制。`service.json` 包含关闭服务使用的校验令牌，请勿分享。

## 模块

- `src/player`：单一音频实例、媒体事件、异步切歌和资源释放。
- `src/sources`：本地文件和远端直链适配器。
- `src/domain`：数据模型、队列规则、LRC 解析与当前歌词定位。
- `src/storage`：IndexedDB 仓储。
- `src/features`：音乐库状态、导入、列表、队列、播放栏、歌词页和弹窗。
- `src/styles`：布局、统一白色主题和页面过渡。
- `scripts`：本机服务和双击启动入口的内部实现。

## 导入音源资源包

在“设置 → 导入资源 ZIP”选择带有 `manifest.json` 和其声明脚本的资源包。导入后侧边栏出现“发现”，可以选择音源、切换频道和分类、搜索专辑、打开目录及播放。包仅保存在当前浏览器的独立 IndexedDB 数据库，同名包重新导入会替换旧版本；移除最后一个包后隐藏“发现”。不会上传资源包至 GitHub，也不随网站分发第三方脚本。

`src/resources` 独立实现插件宿主，脚本运行在 Worker 内的 QuickJS 隔离环境，提供受限网络、HTML 解析和 SDK 工具。导入阶段禁用联网，限制 ZIP 展开体积、脚本内存、执行时间、请求次数和响应体积。插件不能读取音乐库或浏览器全局对象。

GitHub Pages 是静态网页：接口仍须允许浏览器跨域访问，浏览器不能伪装 Referer、Cookie 或任意 User-Agent，也不支持原生宿主的页面验证和音频嗅探。已验证 ShunSources v5.6 的 38 个音源可以注册，全球电台能加载目录并播放；不代表所有来源可用。本地双击启动服务及 Vite 开发/预览服务统一转发公开音源接口，支持 GET、受限 POST、HTML/JSON、压缩响应、Referer 与 User-Agent。服务仅监听本机；每次请求及重定向都校验目标和 DNS，并把连接固定到已校验的公开 IP，拒绝本机、私网、带凭据的地址及账号 Cookie。GitHub Pages 不具备这一服务能力，线上版仍需另外配置后端。

## 下载音频与字幕

- 歌曲列表的更多菜单、专辑章节右侧提供单项下载；底部播放栏不放下载入口。
- 歌曲列表和专辑目录都支持“批量下载”，可多选或全选当前已加载的内容。音源章节逐个解析最新地址，不需要先播放，也不改变播放队列。
- 单项没有字幕时直接保存音频；有歌词或字幕时自动打包 ZIP。批量统一打包 ZIP，按序号保留顺序与同名条目，已有 LRC、SRT、VTT、纯文本字幕随音频一起保存。没有字幕不生成占位文件，也不自动生成字幕。音源必须实际提供字幕内容。
- 任务面板显示进度，可取消。部分失败时保留成功项，并在 ZIP 内附失败清单；全部失败不生成空包。浏览器负责最终保存位置。
- 浏览器内存打包每批最多 256 MB，单文件最多 100 MB；超出时保留已成功文件，并提示剩余项分批下载。直播流与需登录、特定请求头的来源不保证可下载。
- 本地启动、开发、预览服务统一转发公开音频播放与下载，不再逐域名配置。支持 Range、经校验的跳转和音源提供的 Referer；HLS 清单、子清单、分片和公开密钥统一改写为本地路径。浏览器原生 HLS 优先，否则按需加载 HLS.js；HLS 不作为单文件音频下载。所有目标同样校验公开 IP，跨域页面不能调用本地服务。

## 音源兼容检查

已对用户本地 ShunSources v5.6 的 38 个音源逐个检查首个分类、首个条目详情和一个标为免费的章节。修复 `byId`、`tag`、`hasClass`、HTML 实体解码及文本空白兼容后，30 个来源返回内容列表，25 个来源解析到音频地址；这是接口抽样结果，不代表每首曲目都可播放。网易云音乐已在浏览器实测歌单、目录和连续播放。

其余来源的限制分为：需要原生渲染/嗅探（念音网、听中国、13听书网、悦听吧），需要登录会话（哔哩哔哩、抖音），站点拒绝/超时/连接中断（有听网、听友听书、爱听书、起点有声网、29听书网），以及首个分类或条目为空（懒人听书、酷我畅听）。这些来源没有伪装为已可用。完整结果见 [音源检查记录](docs/resource-audit.json)。

复测命令（读取调用者提供的本地资源包文件夹，不会把第三方脚本复制到仓库）：

```sh
node --experimental-strip-types scripts/audit-resources.mjs /path/to/Sources-v5.6
```
